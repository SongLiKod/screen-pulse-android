## 一、项目背景与痛点
### 1.1 行业现状
目前市面主流安卓录屏软件均存在明显短板，无全能纯净工具：
1. 商业录屏软件：充斥开屏、弹窗、结束页广告，核心高清录制、区域录屏、无损压缩功能强制付费开通会员；
2. 免费工具：高帧率录制卡顿掉帧、音画不同步、人声混杂杂音、长时间录制闪退崩溃；
3. 手机系统自带录屏：极致简陋，无区域录制、无参数自定义、无快捷键、无智能压缩，无法满足精细化使用需求。

### 1.2 竞品优缺点汇总
#### 1. AZ Screen Recorder
优点：无录制时长限制、免费无水印、支持1080P/60fps、系统内录、悬浮窗操作
缺点：广告繁多、高级功能付费、长时录制掉帧卡顿、音频调节粗糙

#### 2. Mobizen录屏
优点：轻量化、长时间录制稳定、自带基础压缩、游戏录制适配好
缺点：UI老旧、免费版带水印、高清音质付费、后台耗电高

#### 3. XRecorder
优点：界面简洁、操作简单
缺点：广告泛滥、高帧录制卡顿、无精细化音频调节、压缩效果差、视频易损坏

#### 4. 安卓系统自带录屏
优点：原生适配无卡顿、无广告、零安装
缺点：功能单一、不支持区域录制、无可自定义参数、无快捷键、压缩固定、人声收音嘈杂

### 1.3 项目核心目标
整合所有竞品优势，规避全部行业痛点，打造一款**全功能免费、纯净无骚扰、极致流畅、音画优质、低存储占用、轻量化稳定**的安卓录屏工具，覆盖网课、游戏、直播、教程制作、日常截屏全场景。

## 二、用户核心需求
1. 性能需求：录制实时同步、0延迟、全程不卡顿、不掉帧、长时录制稳定不中断
2. 画质需求：全参数自定义分辨率、帧率、码率，支持全屏/区域录制，无水印
3. 音频需求：支持三种纯净收音模式，人声降噪清晰、系统音无杂音、音画同步
4. 操作需求：悬浮窗、自定义快捷键、倒计时录制，操作便捷
5. 存储需求：画质无损智能压缩，大幅降低视频体积，节省手机存储空间
6. 体验需求：永久零广告、零内购、零推送、零水印，轻量化低耗电、不占用手机资源
7. UI主题需求：主色调绿色；支持跟随系统、浅色模式、深色模式三种主题，切换即时生效无需重启App。

## 三、详细功能需求
### 3.1 核心录制性能（最高优先级）
- 画面录制与屏幕操作**毫秒级实时同步**，无延迟、无滞后、音画完全对齐
- 支持30fps/60fps稳定录制，全程无掉帧、无卡顿、无画面撕裂
- 无录制时长限制，支持数小时长时间连续录制，无闪退、无自动中断
- 后台轻量化运行，低CPU、低内存占用，录制过程不导致手机发烫、卡顿

### 3.2 画质自定义功能
1. 分辨率：支持240P、480P、720P、1080P、2K、4K档位选择，支持手动自定义分辨率参数
2. 帧率：30FPS、60FPS自由切换，锁定帧率稳定输出
3. 码率：支持智能适配+手动自定义调节，平衡画质与文件体积
4. 录制模式：支持**全屏录制 + 自定义区域录制**，可手动框选任意屏幕区域精准录制
5. 水印规则：默认全局无水印，支持用户自主添加自定义文字/图片水印（可选开关）
6. 画面适配：自动适配手机横屏、竖屏，画面无拉伸、无裁剪、无模糊

### 3.3 精细化音频录制功能
内置三种核心收音模式，全覆盖使用场景，模式可一键切换：
1. 仅系统声音：纯净收录手机内部音频，完全隔绝外界噪音、人声，无杂音、无破音，适配网课、影视、游戏原声录制
2. 仅麦克风声音：单独收录外界人声，自带AI智能降噪，过滤风声、底噪、环境杂音，人声清晰通透
3. 系统声+麦克风混合声：双向同步收音，自动平衡双音源音量，不盖音、不炸音，适配解说、配音、教程讲解场景
- 支持系统音量、人声音量单独微调
- 适配安卓10+原生系统内录，无需ROOT，全机型兼容

### 3.4 快捷操作功能
1. 悬浮窗控制：桌面常驻可拖动悬浮窗，支持一键开启、暂停、继续、结束录制、快速截图，可一键隐藏不遮挡画面
2. 自定义快捷键：支持手机物理按键自定义录制启停快捷键
3. 倒计时录制：支持3s/5s倒计时启动，预留操作准备时间
4. 状态栏状态提示：录制中实时显示状态，清晰区分空闲/录制/暂停状态

### 3.5 智能视频压缩存储功能
1. 核心算法：硬件编码无损压缩技术，**画质肉眼零损耗**前提下，压缩视频体积，比主流软件节省30%-50%存储空间
2. 三档压缩模式：
   - 极速压缩：极致缩小体积，适合普通日常录制
   - 均衡压缩：画质与体积平衡，通用场景首选
   - 高清无损压缩：保留原始极致画质，适合自媒体、高清教程录制
3. 格式标准：默认输出通用MP4格式，全设备兼容，无视频损坏、无法播放问题
4. 本地文件管理：自动归类保存录屏文件，支持预览、重命名、删除、一键分享

### 3.6 辅助实用功能
1. 画中画录制：支持前置摄像头悬浮录制，窗口大小、位置可自定义
2. 实时屏幕标注：录制中支持画笔、文字、箭头标注，适配教程讲解
3. 轻量化剪辑：支持视频裁剪、片段截取、时长修剪，无需第三方工具

### 3.7 UI主题设置（新增 V1.1）
#### 3.7.1 主题模式选项
设置页面提供单选选项：
1. 跟随系统（**默认**）
2. 浅色模式
3. 深色模式

- 切换主题**立即生效，不需要重启应用**。
- 悬浮窗控件颜色跟随App当前主题同步变化。

#### 3.7.2 色彩规范（绿色主题体系）
- 主色（品牌绿）：`#2E7D32` 深绿：主按钮、高亮操作
- 辅助绿：`#4CAF50`：开关激活、次要按钮、进度条
- 淡绿：`#E8F5E9`：浅色模式卡片选中背景
- 浅色模式：白底，深灰文字；卡片淡绿底色
- 深色模式：深暗色背景，降低绿色饱和度防止刺眼；文字浅白；卡片深绿灰调
- 错误提示：标准红色，不和绿色冲突
- 所有颜色禁止硬编码，全部使用主题资源引用。

#### 3.7.3 适配范围
设置页、录制参数页、视频列表、预览页面、悬浮窗全部适配浅色/深色；满足无障碍对比度。

## 四、非功能需求
### 4.1 体验规范（硬性死规则）
- 全程**无开屏广告、无弹窗广告、无插屏广告、无推送广告**
- 所有功能永久免费，无会员、无内购、无付费解锁项目
- 无后台推送、无强制更新、无捆绑下载、无隐私弹窗骚扰

### 4.2 性能规范
- 兼容安卓8.0及以上所有主流安卓机型
- 录制延迟＜0.1秒，音画100%同步
- 长时间录制无内存泄漏、无闪退、无进程被杀问题
- 安装包体积小，后台低耗电、低内存占用

### 4.3 隐私规范
- 所有录制文件仅本地存储，不上传云端、不窃取用户数据
- 仅申请录屏、麦克风、存储三项必要权限，无多余隐私权限获取

## 五、功能禁用与避坑清单
1. 禁止任何形式的广告、付费入口、会员体系、内购项目
2. 禁止默认水印、强制弹窗、消息推送、捆绑安装
3. 禁止录制卡顿、掉帧、延迟、音画不同步问题
4. 禁止压缩后画质模糊、视频损坏、格式不兼容问题
5. 禁止功能冗余臃肿，全程保持软件轻量化运行

## 六、验收标准
1. 界面纯净无任何广告、付费入口、推送提示，所有功能免费可用
2. 全屏/区域录制实时同步，30/60fps录制全程流畅，无卡顿、掉帧、延迟
3. 三种音频模式收音正常，降噪效果达标，人声纯净、系统音清晰、混音平衡无杂音
4. 所有画质参数、压缩档位、快捷键、悬浮窗功能正常生效
5. 压缩后视频体积明显缩小，画质无肉眼可见损耗，视频可正常播放
6. 连续3小时以上长时间录制稳定，无闪退、中断、手机卡顿发烫问题
7. 权限合规、无隐私窃取行为，文件管理功能正常可用
8. 主题三种模式（跟随系统、浅色、深色）切换即时生效，无需重启应用；全部页面、悬浮窗UI跟随主题变化。
9. 主色调绿色在浅色、深色模式下显示正常，文字对比度达标，无看不清文字、控件融合背景的问题。
